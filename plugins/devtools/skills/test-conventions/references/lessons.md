# test-conventions: review lessons

- Test a DB helper directly against the DB to exhaust permutations cheaply (PR #1086)
- Split or rename a second test file for the same source unit (PR #1084)
- Merge `it` blocks with identical setup for speed (PR #1084)
- Seed e2e data through the service layer, not hand inserts (PR #1799)
- The harness moved from `services/api/src/test/helpers` to `packages/common/testing` (PR #2172)
- A wholesale `.unit.test.ts` rename left the integration project with no tests (PR #2011)
- Replace an `as` cast with the file's existing type guard (PR #1789)
- `as unknown as X`, `as never` and narrowing casts in fixtures hid contract drift (PR #1831, #1845, #1861)
- Thread an optional factory param instead of casting at the call site (PR #1845)
- A precedence test seeded both sources with the same email, so it proved nothing (PR #2170)
- A data-manager shortcut skipped the encoder's validation (PR #2172)
- CodeQL blocked `Math.random()` in a test helper (PR #2172)
- A shared resolver was tested only at the CSV surface, not the list preview (PR #1838)
- Tests that only exercised a Zod schema were deleted (PR #1999)
- A singular/plural branch tested only with count 1 (PR #2054)
- A guard keyed on an untested Supabase `CHANNEL_ERROR` shape (PR #2081)
- A stubbed DB missed the GoTrue/Twilio `+` phone mismatch; `@inngest/test` skips debounce/singleton (PR #2161)
- A webhook verifier needed handler-level tests from the raw body (PR #2159)
- A regression test must force the buggy path (PR #1558)
- Pin distinct sort keys and nested relations when reworking query internals (PR #1516)
- Assert new output fields survive tRPC's output parse (PR #1551)
- Add a no-leak test for HIDDEN records with real data (PR #1553)
- A data-manager helper must throw on an unknown phase id (PR #1694)
- Use `csv-parse/sync` (strict) instead of a hand-rolled reader (PR #1750)
- Test the combination of a tall dialog with sticky header and footer (PR #1796)
- `as const` in fixtures is not a type assertion (PR #1788, #1797)
- Prove a cross-tab storage invariant with two pages (PR #2057)
- Select with `data-testid`, not `.locator('..')` chains (PR #1699)
- A test comment listed an assertion the test did not make (PR #1699)
- Replace a fixed 600 ms delay with an auto-retrying assertion (PR #1639)
- Do not wait for `networkidle` (PR #1073)
- Fix new a11y violations rather than deleting ledger entries (PR #1505, #1521)
