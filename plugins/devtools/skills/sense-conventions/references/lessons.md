# sense-conventions: review lessons

One line per lesson. Each one gives the incident behind a rule in SKILL.md.

- `packages/ui` was deleted (PR #1790), after the migration (PR #1662, #1727, #1738, #1740, #1741)
- RTL sweep to logical properties (PR #1745, #1751)
- `bg-white` on a `loading.tsx` shell (PR #1795), a reviews shell (PR #1843), the assignment dialog (PR #1848) and a search notice (PR #1852)
- A bot flagged `text-sm`. The `theme.css` comment allows it (PR #1892)
- A suggested `text-label` would have rendered a 12px legend larger than its `<h3>`. Rebut with numbers (PR #2124)
- `text-title-*` retired (PR #1754). Pre-sense token layer dropped (PR #1753, #1756, #1791)
- `stroke-[1.5]` flagged twice (PR #1673, #1726)
- A repeated arbitrary dialog height should be a token (PR #1796)
- `w-[36rem]` in a story (PR #1797)
- `duration-450` emitted no CSS on a drawer and a popup (PR #1688)
- `text-5xl sm:text-display` shrank between 640 and 767px (PR #2041)
- `cursor-default` dead next to `cursor-pointer` (PR #1671)
- `opacity-100` under an `opacity-50` wrapper did nothing (PR #1675)
- `aria-label={reviewerNames}` replaced "3 Reviewed" (PR #1711)
- Upload button labelled "Profile photo" instead of the action (PR #1626)
- A `pointer-events-none` loading button was still keyboard-activatable (PR #1670)
- Menu items that early-return were still focusable (PR #1669)
- `showDragHandle` defaulted to true with no handle props (PR #1659)
- Toggle label stuck at "Advance" (PR #1711)
- Sortable headers lacked `aria-sort` (PR #1702)
- An href-less anchor with `target="_blank"` (PR #1626)
- `dir='auto'` default on headers. `tabpanel` without a tab (PR #1622)
- `TagGroup` truncated English tags from the wrong end on Arabic pages (PR #2168)
- `<p>` over `<span>` for standalone text (PR #1943)
- Prose links must be underlined (PR #1524)
- `ScrollArea` in the dialog and a raw overflow div in the panel (PR #1848)
- A reviewer asked for a list row to move to `@op/sense` (PR #1966)
- `CurrencyField` closed without design approval. Reuse `NumberField` + `prefixText` (PR #1775)
- `window.open` needs `noopener,noreferrer` (PR #1522)
- `BannerImageField` takes `renderPreview` instead of importing `next/image` (PR #1480)
- A sense component takes one `copy` prop object (PR #1626)
- Sentence-case labels across all locales (PR #1649)
- The hero title is the `h1` (PR #1482)
- `phase.name ?? ''` rendered "Reviews from " (PR #1701)
- `next/image` `fill` + `object-cover` in a `size-8` container (PR #1670)
- Storybook needs the built `@op/styles` dist on a fresh clone (PR #1782, #1784)
