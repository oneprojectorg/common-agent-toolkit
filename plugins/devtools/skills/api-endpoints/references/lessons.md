# api-endpoints: lessons

- A router that imported the DB and handled base64 was replaced by thin sign/update routers ("We never pull in the DB to the router level") (PR #1480)
- `commonAuthedProcedure` was split into the 4-tier model (PR #1240)
- Custom rate limits added by reflex get pushed back; use the default (PR #1580)
- Comment reporting reused `moderation.flagItem` with `itemType: 'post'`; no new endpoint (PR #1511)
- New optional `'x-phase'` / `phaseId` fields documented what absent means (PR #1532)
- Hand-rolled `limit` left one endpoint unbounded; use the shared pagination builders (PR #1968)
- `phaseId: z.string().optional()` let `''` collide with the NULL sentinel under a `COALESCE` unique index; fixed across add/remove/list siblings (PR #1679), then folded into the shared schema (PR #1690)
- Narrowing the `reviewsPolicy` enum without `.catch()` would fail to decode existing rows (PR #1666)
- The map endpoint mirrors `proposalFilterSchema` minus cursor/limit and reuses `proposalSchema` (PR #1553)
- An encoder listing only `documentContent` silently stripped `previewText` (PR #1551)
- `listProposals` returned too much; omit heavy fields (PR #1563); list rows ship `previewText`, not fragments (PR #1551)
- `proposalProfileColumns` narrows lateral selects and drops the `tsvector` (PR #1551)
- `includeDocumentContent` is kept out of `proposalFilterSchema` so clients can't set it (PR #1551)
- Auth-only fields (phone) added to a user read: "fix this in the encoder/schema level" (PR #1297)
- `getMyAccount` cache purge must be awaited, matching `completeOnboarding` / `switchProfile` (PR #1556)
- Over-registered delete channels (`collectionResources` on a deleted collection) (PR #1229)
- CSP report endpoint trusted `Content-Length`; fixed with a streaming cap and verified with a 200 KB chunked body (PR #2175)
- Twilio handler tests cover signed, missing, tampered, wrong-token and missing `TWILIO_AUTH_TOKEN` cases; use Common errors (PR #2159)
- SMS reply to unknown senders needs its own Inngest `rateLimit` keyed on `event.data.from` (PR #2161)
- A static `YES` reply recorded a phone verification that never happened; `waitForEvent` matched only on the sender (PR #2161)
