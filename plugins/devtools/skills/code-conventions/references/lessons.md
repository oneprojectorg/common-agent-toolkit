# code-conventions: review lessons

One line per lesson. Each rule is already in SKILL.md unless it is listed here only.

- Do not rewrite surrounding code that the task did not ask for. If you cannot say what the rewrite bought, revert it (PR #1909)
- Do not add a feature flag nobody planned a rollout for. Gate only the surface that must be hidden (PR #1930)
- A PR made of only a helper with no caller ships dead code. Split a stack by reviewable unit, not by layer (PR #2113)
- When you patch a call site instead of the upstream cause, name the cause and file it (PR #1750)
- A Redis preflight and a `turbopack.root` pin with no failure observed in the repo were removed as speculative (PR #1750)
- Run `pnpm health --base origin/dev` on grown files. Two functions crossed cyclomatic 20 / cognitive 15 because of nested ternaries (PR #1819)
- Rebut a wrong bot finding with the mechanism and precedent counts, not with confidence. Concede the valid half separately (PR #1788, #1805)
- `as const` flagged by a bot is a const assertion. Removing it widens the literal (PR #1788, #1797)
- One `isRecord` guard replaced four object casts and seven test casts, and the tests got stricter (PR #1770)
- A map callback named `(p) =>` that escapes its immediate scope needs a real name (PR #1293)
- A name for a state the row is not in yet (`getLinkedProposal`) misleads (PR #1856)
- `String(a) === String(b)` fixed a dnd-kit `findIndex` returning -1 and corrupting `arrayMove` (PR #1624)
- Two booleans for a three-state result: use a string union (PR #1851)
- A merge guard checked only the target's outgoing edge and allowed chains. Check both directions (PR #1789)
- An effect that sets an inline style also needs the branch that clears it (PR #1813)
- A capability gate enabled a mode without requiring the method the mode needs (PR #1836)
- A write skipped the `assertInstancePhase` that its read sibling calls (PR #1848)
- A unique index covered fewer columns than the JS predicate, so two unlocked checks both passed (PR #1789)
- Re-key encodings as `field:index`, not `field[index]`, so a numeric id cannot parse as an index (PR #1540)
- A cleared headline got a render-side default. The accepted fix rejected empty values at the API (PR #1845)
- A `??` onto an older value brought back a category the author had cleared (PR #1843). A legacy `0` meant unknown (PR #1838)
- A one-shot header de-duplication still produced duplicate CSV headers. Use a loop (PR #1847)
- A no-title fallback capitalized a field key. Do not re-case text (PR #1847)
- GoTrue stores phone numbers without `+` and Twilio sends them with `+`. Normalize in the parser (PR #2161)
- `MessageSid ?? ''` made all sid-less messages dedupe against each other. Reject a missing id (PR #2161)
- A Supabase OTP length is project-configurable. A fixed 6-slot input and a "6-digit code" label broke on 8 (PR #2073)
- Raw `Error` from a service made the router string-match messages (PR #1017)
- `.catch(() => null)` around an assert swallowed a DB hiccup and returned an unfiltered list (PR #1633)
- A validator leaked an array index as the field name and blamed the user for a duplicate-label config fault (PR #1786)
- A diagnostic assumed every `oneOf` was a selection list and misdiagnosed custom schemas (PR #1786)
- A DB retry classifier matched an Auth `ECONNRESET` and replayed a memoized rejection (PR #1861)
- Throwing inside a batched send re-blasts recipients whose batches already succeeded (PR #1919, #1924)
- A durable retry reused memoized eligibility and sent a reminder after the phase ended (PR #1718)
- A durable step logged a `rejected` SMS and then waited for the full timeout for a reply (PR #2161, #2163)
- A persisted currency code crashed `Intl.NumberFormat` in render. Guard it in the shared helper (PR #1899)
- Ported debug code and TODOs read as new code. Fix them, or say in the PR why you kept them (PR #1661, #1685, #1711)
- `url.includes(host)` fails CodeQL incomplete URL sanitization. Compare `hostname` exactly (PR #1523)
- Unparseable timestamps fail closed. Delete the auth user before the profile (PR #1507)
- Log level by severity, not a 1:1 `console` conversion (PR #1587, #1605)
- Do not put a phone or email in log fields deliberately. Log `messageSid` or `error.code` (PR #2015, #2161, #2163)
- `console` in `scripts/` and `services/db/migrate.ts` is correct. Decline the bot finding (PR #1824, #1854, #1860)
- A job that needs a secret on `pull_request_target` needs the `fork-ci` environment gate (PR #1866)
- A job that runs branch code belongs in its own `pull_request` workflow (PR #1866)
- The fork gate releases the secret, and `pnpm install` runs branch lifecycle scripts. Install with scripts disabled and fix all three workflows (PR #2078, #2084)
- A `workflow_run` publisher must compare the SHA the measured job checked out, not `workflow_run.head_sha` (PR #2151, #2167)
- Match a sticky comment on the marker and the bot author (PR #2151)
- A shell function in an `||` list loses errexit. `git commit -- <dir>` commits unrelated edits (PR #2144)
- `cmd_a; status=$?; cmd_b; exit $status` hides `cmd_b`'s failure (PR #2144)
- `dompurify` imported through a transitive `posthog-js` copy failed on a clean install (PR #2178)
- Delete components and assets that the change orphaned (PR #1517)
- Cut about 140 lines of narrating comments to about 40 (PR #1847). Comments that only restate code get removed (PR #1868, #1870, #1935, #1803)
- When you remove polling, delete the comments that describe polling (PR #1750)
- Do not carry a moderation term (CSAM) into a general mechanism's comments (PR #1815)
- A JSDoc must document the component and its args, not narrate the change (PR #1803, #1851)
