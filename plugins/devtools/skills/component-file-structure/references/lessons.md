# component-file-structure: review lessons

One line per lesson. Each one gives the incident behind a rule in SKILL.md.

- `RichTextEditorToolbar` declared `ToggleButton` inside its body, so focus dropped on every keystroke (PR #1702)
- A decorative suspense suffix with no error boundary would have blanked the whole reviewer tab (PR #1689)
- Scope `<Suspense>` + boundary to the toggled map view (PR #1553)
- A client-side filter on a paged list merged only as a stopgap. The real fix is an API filter (PR #1923)
- `retry: false` outlived the `enabled` condition it was written for (PR #1817)
- `(x?.length ?? 0) !== 1` was true while loading and flashed a category tag (PR #1692)
- `stateUnknown = data === undefined` fixed controls that looked unpressed during the first fetch (PR #1770)
- A double-click on a remove chip fired twice and showed an error toast after a success (PR #1683)
- A confirm-dialog toggle snapped back without a pending value (PR #1696)
- Select-all over the 500-id cap produced a raw Zod toast (PR #1848)
- A restore confirm was enabled before its payload loaded and silently did nothing (PR #1725)
- The merge menu was offered for a proposal that the service rejects because it has incoming merges (PR #1831)
- `LaunchProcessModal` inferred a publish from the cache. The server now returns `didPublish` (PR #2092)
- A hand-rolled once-per-session ref duplicated PostHog's own survey frequency control (PR #2092)
- A character counter used `length` and the validator used `trim().length` (PR #2158)
- Tighter caps rejected existing stored headings on save (PR #2158)
- Per-field errors keyed on a reused draft id showed under a new field (PR #2158)
- A form builder dropped `minimum`, `pattern` and `format` on save. Refuse records you cannot write back (PR #2096)
- `canLinkToProfile` was applied to the name but not the avatar (PR #1695)
- Avatar and name linked to two different routes for one entity (PR #1567)
- Single-fetch `/overview`: the duplicate `getInstance` was removed (PR #1332, #1417)
- `.catch(() => undefined)` in RSC rendered a section that was broken but looked empty (PR #1341, #1350)
- `handleServerError` maps a `CommonError` cause to `notFound()` / `forbidden()` (PR #1526)
- An export status query with no error handling showed "timed out" for a successful export (PR #1750)
- An over-cap `?q=` from a shared link broke the whole list. Clamp on read (PR #1788)
- A renamed tab value `other` → `completed` silently broke bookmarks (PR #1773)
- `?new=true` replayed "Create proposal" for co-authors. Remove it with `history: 'replace'` (PR #1828)
- The map view toggle was hidden below `sm`, so mobile users had no way back (PR #1807)
- `JoinDecisionButton` reads nuqs under `<Suspense>` with a plain-link fallback (PR #1556)
- The proposal side sheet lost `proposal_viewed`, the decision scope check and mobile deep links (PR #2136, #2176)
- The sheet claimed `?proposal=`, which the promotion flow already used (PR #2176)
- "Read full proposal" bubbled up and toggled the ballot selection (PR #2176)
- A count hidden at zero looked like a bug (PR #1822)
- The header counted eligible reviewers while the table rendered all reviewers (PR #1848)
- An optional slug built `/decisions/undefined/...` (PR #1820)
- A success from one translation request hid the retry banner when the other failed (PR #1798)
- A browser-native `type="url"` blocked submission before the schema ran. Audit equivalent fields (PR #1578)
- A multi-step submit read local state that reset on remount (PR #1583)
- Wrap storage access so that quota or private mode degrades gracefully (PR #1608)
- A per-tab sign-out flag let a second tab write the account cache back. Clear storage on `SIGNED_OUT` (PR #2057)
- A retry after a refetch published a different winner set than the one confirmed (PR #2180)
- A sanitizer stripped an iframe-only embed and rendered an empty player (PR #2178)
- Use the mutation's `onError` (PR #1293)
- `useCreateProposal` takes a navigate callback instead of a route (PR #1291)
- No cleanup in `TranslationDetectionContext` (PR #1811). A literal key `resources` collided (PR #1799)
- An effect never cleared `paddingBlock`, and a trailing `{...rest}` replaced the internal ref (PR #1813)
- A callback ref into state replaced `ref.current` in an effect (PR #1558)
- `onEditorReady` re-fired on each new callback reference (PR #1623)
- A `bounds` array prop looped `fitBounds`. Normalize it internally (PR #1627, #1651)
- Pass the whole `steward` (PR #1439). Pass one permissions object (PR #1470). Too many props means compose (PR #1450)
- Boolean show/hide props are a code smell across PRs (PR #1859)
- `title` was silently dropped for non-PDF content (PR #1626)
- `RichTextEditor` omitted `required` from `useRichTextEditor` (PR #1623)
- A masonry skeleton waited for a client library. Use CSS columns (PR #1455)
- `loading.tsx` mirrors the header and grid classes (PR #1518)
- `SkeletonText lines={10}` rendered 30 bars for three labels (PR #1693)
- A status map was typed `Record<string, string>` with a `?? status` raw fallback (PR #1848)
- A one-place file should be colocated (PR #1585)
- Inline `@keyframes` moved to the shared stylesheet (PR #1624)
