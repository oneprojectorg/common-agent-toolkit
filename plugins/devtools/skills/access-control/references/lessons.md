# access-control: lessons

- Request-memoized access-user loaders (PR #1220); the durable cache needs invalidation at every role/membership mutation site (PR #1339)
- Prefer `permission.READ` for read gates, even admin views (PR #1208)
- Personal-profile owners 403'd on avatar upload via the throwing assert; use `getProfileAccessRoles` + own-profile check (PR #1612)
- Don't leak `resolveAccessUserIds` / public-union into `proposalVisibility.ts`; the public grant is at instance level (PR #1873)
- `getExportStatus` should use `assertInstanceProfileAccess` or an owner check, not a bespoke lookup (PR #1851); same shape in `reviewHelpers.ts` (PR #1815)
- Opening `profile.addRelationship` a tier exposed org↔individual edges; split into `decision.addProposalRelationship`; likes gated like comments on `SUBMIT_PROPOSALS` (PR #1580)
- Phone number nearly leaked through a user read; filter at the encoder (PR #1297)
- Relationship read applied moderation/visibility predicates to only one end, twice in one file (PR #1789)
- `collaborationDocId` was client-writable and signed into a Tiptap JWT; derive `proposal-${id}`, guard omitted fields, and repeat the results-phase check on `getCollabToken` (PR #2067, #2087, #2088)
- `decisions: UPDATE || profile: UPDATE` let every Member edit every proposal; gate on the bit collaborators share; prefer the assert (PR #1879)
- A new contributing-ideas read selected raw `name` / `avatarImage` and exposed anonymous submitters; now `isAnonymousAuthor` in `proposalAuthor.ts` (PR #1856)
- Legacy instance org fallback must not spread to new writes (PR #1848); removed from active-process writes (PR #1862)
- Rethrow `AccessControlException` as `UnauthorizedError` (PR #1245)
- `ALL_TRUE_ACCESS` pulled admins into a throwing phase lookup; short-circuit admin, and treat lookup failure as deny (PR #1694)
- Least-privileged invite default ignored profile admin and only saw page one (PR #2165)
- `<AccessBoundary required={{}}>` denies (PR #1016)
- Gate Delete, not the whole menu; Report stays visible (PR #1511)
- `ViewProposalsList` gated on admin only, while `VotingProposalsList` used `canManageProposals || proposal.isEditable` (PR #1568)
- `ReviewPage` mirrored `canReadPhaseReviews` on the client and missed `isPhaseAtOrBefore`; return it from the API (PR #1822)
- `useMaybeUser` outside a provider; `useCanLinkToProfile` for walled-garden links (PR #1519)
